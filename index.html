📍 ڈیٹا کہاں محفوظ ہو رہا ہےWhere is my data saved?

📁 ڈیٹا فولڈرData Folder

ایک فولڈر منتخب کریں۔ ہر بار فارم محفوظ کرنے پر اس کی فائل خود بخود اسی فولڈر میں بھی محفوظ ہو جائے گی۔Choose a folder. Every time you save a form, its file is also saved automatically in this folder.

نوٹ: یہ سہولت Chrome (کمپیوٹر یا نئے اینڈرائیڈ ورژن) میں چلتی ہے۔ اگر براؤزر سپورٹ نہ کرے تو بیک اپ والا آپشن استعمال کریں۔ براؤزر بند ہونے کے بعد پہلی بار محفوظ کرتے وقت اجازت دوبارہ پوچھ سکتا ہے۔Note: works in Chrome (desktop or recent Android). If unsupported, use Backup instead. The browser may ask permission again on the first save after restart.

💾 بیک اپBackup (Export)

تمام محفوظ فارم ایک خفیہ (Encrypted) فائل کی صورت میں محفوظ کریں۔ فائل کھولنے کے لیے آپ کا پن درکار ہوگا۔Save all saved forms as one encrypted file. Your PIN is required to open the file later.

📂 بحالیRestore (Import)

پہلے سے محفوظ بیک اپ فائل واپس لوڈ کریں۔ اس کے لیے وہی پن درکار ہوگا جو فائل بناتے وقت استعمال ہوا تھا۔Load a previously saved backup file. The PIN used when creating it is required.

🖨️ پرنٹ / شیئرPrint / Share

فارم پُر کرنے کے بعد "پرنٹ / PDF" پر کلک کریں، پرنٹ ڈائیلاگ میں "Save as PDF" منتخب کریں — اس طرح ایک اصلی A4 PDF فائل بن جائے گی جسے آپ WhatsApp یا کسی بھی ایپ سے شیئر کر سکتے ہیں۔ "خالی فارم" بٹن سے بغیر ڈیٹا کے خالی A4 ٹیمپلیٹ پرنٹ ہوتا ہے۔After filling the form, tap "Print / PDF", then choose "Save as PDF" in the print dialog — this creates a real A4 PDF file you can share via WhatsApp or any app. The "Blank Form" button prints an empty A4 template with no data.

⚠️ اہم: اگر "پرنٹ" پر کلک کرنے سے کوئی ڈائیلاگ نہ کھلے، تو ہو سکتا ہے فائل WhatsApp یا کسی اور ایپ کے اندرونی (in-app) براؤزر میں کھلی ہو — یہ پرنٹ سپورٹ نہیں کرتے۔ فائل کو محفوظ کر کے Chrome یا Safari جیسے اصل براؤزر میں کھولیں، پھر پرنٹ بٹن آزمائیں۔Important: If tapping "Print" opens no dialog at all, the file may be open inside WhatsApp's or another app's built-in browser — these do not support printing. Save the file and open it in a real browser like Chrome or Safari, then try the print button again.

ℹ️ معلوماتAbout

یہ ایپ مکمل طور پر آفلائن کام کرتی ہے۔ تمام ڈیٹا آپ کے موبائل/کمپیوٹر میں IndexedDB میں محفوظ ہوتا ہے اور کہیں انٹرنیٹ پر نہیں بھیجا جاتا۔ اس میں پانچ فارمز شامل ہیں: فہرست بقایاداران، سفر خرچ، آڈٹ رپورٹ ضلع، آڈٹ/اکاؤنٹ برانچ، اور امارت آڈٹ رپورٹ۔This app works fully offline. All data is stored in IndexedDB on your own device and never sent to the internet. It includes five forms: List of Defaulters, Travel Expense, District Audit Report, Audit/Account Branch, and Amarat Audit Report.
